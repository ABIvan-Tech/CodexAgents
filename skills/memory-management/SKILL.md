# Memory Management

Use the project's documented memory location and policy when one exists. Distinguish durable, verified decisions and recurring lessons from tentative plans, session notes, and unverified observations. Include context and references sufficient for later verification; reconcile contradictions rather than silently overwriting them.

Do not create or modify personal memory unless explicitly requested. Do not assume VS Code session memory or a particular `.agent-memory` layout exists. Preserve existing files and obtain authorization for deletion. Follow any more specific project and user instructions.
