# Git Worktree

Choose a worktree when independent work would otherwise collide in the same files or require separate branches. Inspect repository status, existing worktrees, branch names, and project instructions first. Agree on ownership and integration order; use a unique path and branch without disturbing existing work.

Verify changes in each worktree before integration. Preserve uncommitted work and resolve conflicts using the applicable project workflow. Do not remove worktrees, branches, or files without the user's authorization; report any remaining cleanup.
