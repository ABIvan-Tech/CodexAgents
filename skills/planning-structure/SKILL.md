# Planning Structure

Choose the smallest useful track: Quick Change for a clear local change, Feature for a few interacting parts, and System for architecture or cross-surface work. Scale the plan to the task.

Identify objective, scope, affected areas, dependencies, ordered slices, and concrete verification. Separate known facts from assumptions. Resolve critical gaps from available evidence; ask only when the answer is necessary and cannot reasonably be inferred. Continue independent work while waiting.

Record a readiness blocker only when a missing decision, dependency, or constraint prevents the next step. Update the plan when scope or evidence changes. Do not require a formal plan for every change.
