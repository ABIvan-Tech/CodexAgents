# Review Core

Review the actual change and relevant context against the requested behavior and project conventions. Prioritize correctness, security, regressions, and meaningful missing tests. Trace a concrete trigger to its impact; cite the smallest useful file and line range.

Report actionable findings in severity order. Explain assumptions and uncertainty, avoid speculative or style-only findings, and mention material verification gaps. State explicitly when no actionable findings were found. Review does not itself establish that tests passed.
