# Multi Model Review

Use when multiple independent reviews have actually been requested or performed. Record which reviewer produced each finding. Group duplicates, then assess each claim against the code, requirements, and reproducible behavior. Agreement can guide prioritization but does not prove correctness; a single well-supported finding can be valid.

Explain disagreements and unresolved uncertainty. Do not claim a provider, model, or review ran unless it actually did. Return actionable findings with impact and precise locations.
